# Point Management inheritance Exception abstract Example

An example of use of inheritance, abstract class and Exception in Java.

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Console input (Scanner), custom exceptions, exception handling, inheritance, interfaces.

## Project structure

- `EtudiantPkg`: Etudiant, EtudiantLicence, EtudiantMastère, IA, IB, IEtudiant, Note
- `Exceptions`: PointException
- `Exceptions.FormeGeometriques`: Carré, Cercle, FormG, Rectangle
- `LesPoints`: Points
- `Pointpkg`: Point, PointColoré, PointEspace
- `src`: Main

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
